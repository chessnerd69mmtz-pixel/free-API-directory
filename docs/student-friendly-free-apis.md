## Research notes

The table has been cross-checked against current provider documentation where available. Important findings:

- **IEX Cloud is retired**: the API was discontinued on August 31, 2024, so its old free tier must not be presented as a current offer. citeturn2search1turn2search19
- **PlaceKitten is deprecated** and a current API catalog reports its origin returning HTTP 521. It should be treated as historical/deprecated rather than a dependable current API. citeturn2search9
- **OpenAI API** is not a universal free-tier provider. Current documentation shows a free test request, while complimentary daily tokens are conditional for eligible accounts. citeturn2search16turn2search6
- **Cohere** currently provides free trial/evaluation keys with rate limits; its current docs state 1,000 calls/month for trial keys. citeturn0search8turn0search15
- **CoinGecko** currently documents a free Demo API account and key-generation flow. citeturn0search13turn0search16
- **Merriam-Webster Dictionary API** currently states that non-commercial use is free up to 1,000 queries/day per key, limited to two reference APIs. citeturn2search5
- **Open Library** provides free public APIs but explicitly limits high-volume usage and publishes rate-limit guidance. citeturn0search0turn0search1
- **OpenAQ** now requires an API key for its v3 API and publishes an official registration flow. citeturn0search7
- **NewsAPI** currently offers a $0 Developer plan for development/testing with 100 requests/day, with restrictions on production use. citeturn0search2
- **Fixer** currently advertises a $0 plan and a free API-key flow; current limits should be read from its live pricing page rather than copied from older third-party material. citeturn2search12

**Directory rule:** a provider appearing in this table does not automatically mean unlimited free usage, commercial permission, no-card signup, or permanent availability. Those attributes are shown only when current evidence supports them.
